Card rules — FR-CAT-092

  • Up to the first four filterable pairs, in schema declaration order — admins choose which four by reordering the schema.
  • Fewer than four filterable fields renders only those it has (card 3 above).
  • A category marking none filterable renders a card identical to the home variant.
  • The limit of four is display-only — it never caps how many fields may be marked filterable.
  • Pairs sit in the middle column, between the name and the price.
  • Layout follows a marketplace-style row (image · name + specs · price) rather than a grid tile — a deliberate visual reference, not an SRS requirement.
