TechCart — Brand Kit

Visual identity: color, type, and component styling. The one page in mock-ui/ that is deliberately not grayscale — every other screen stays a structural wireframe on purpose (see README.md), and this page is the bridge from that structure to real styling.

Tokens here are wired for real in buyer-app/src/app/globals.css and admin-app/src/index.css — this page is the reference, those files are the source of truth once they diverge.

Typography

Inter is the shared UI/body font for both apps, loaded via Google Fonts (same CDN-required pattern as the rest of mock-ui/), falling back to the system sans stack. admin-app is Inter-only, deliberately — a dense internal tool where consistency beats personality. buyer-app pairs it with Plus Jakarta Sans as font-display, used only for hero headings and marketing sections — never in admin-app, never in buyer-app body/UI text.

Spacing, radius & elevation

No custom tokens — use Tailwind's default scales directly:

  • rounded-lg for cards, modals, image containers
  • rounded-md for buttons, inputs, badges/pills
  • shadow-sm for resting cards; shadow-md on hover/dropdowns only — avoid heavier shadows
  • p-4 / gap-4 as the default component padding/gutter; p-6 for page-level containers
